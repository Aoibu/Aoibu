# مكتبة Aoibu | المحقق كونان مترجم 🔎

موقع فريق **اويبو للترجمة**: حلقات وأفلام المحقق كونان مترجمة للعربية، وفصول المانجا.
الموقع: **https://aoibu.github.io/Aoibu/**

---

## ✨ إضافة حلقة جديدة (أسهل طريقة)

كل الحلقات الآن موجودة في **ملف واحد**: [`data/episodes.json`](data/episodes.json). لا تحتاج تنشئ ملف HTML لكل حلقة.

### الطريقة 1: لوحة النشر (الأسهل — من الجوال بضغطة زر) 🚀
افتح **https://aoibu.github.io/Aoibu/admin.html**

**أول مرة فقط — ربط اللوحة بـ GitHub:**
1. افتح https://github.com/settings/personal-access-tokens/new
2. Token name: `Aoibu Admin` — Expiration: مثلاً سنة.
3. Resource owner: `Aoibu` — Repository access: **Only select repositories** ← `Aoibu/Aoibu`.
4. Permissions ← **Contents** ← **Read and write**.
5. **Generate token**، انسخه، والصقه في اللوحة ← «حفظ وتجربة الاتصال».

**بعدها لكل حلقة:**
1. اختر: حلقة / فيلم / فصل مانجا.
2. املأ: الرقم (يُقترح تلقائياً)، النوع (مانجا/فلر/…)، العنوان، الصورة (من الجهاز أو رابط)، روابط Drive وMega، القصة…
3. اضغط **«نشر»** ✅ — تظهر في الموقع خلال دقيقة أو دقيقتين، واللوحة تخبرك لما تظهر.

من نفس اللوحة تقدر أيضاً: **تعدّل** أو **تحذف** أي حلقة (تبويب «إدارة المنشور»)، وتغيّر **البانر** والحلقة المميزة في الواجهة، و**تفحص** الملفات.

> 🔒 المفتاح يُحفظ في متصفح جهازك فقط. لا تشاركه مع أحد، وتقدر تلغيه أي وقت من إعدادات GitHub.

### الطريقة 2: يدوياً
انسخ هذا القالب وغيّر القيم، وأضفه في آخر الملف (لا تنسَ الفاصلة `,` بعد الحلقة التي قبلها):

```json
  {
    "id": "1205",
    "number": 1205,
    "title": "من اختطف كونان وأزوسا؟ (الجزء الثاني)",
    "type": "manga",
    "date": "2026-06-28",
    "poster": "https://i.ibb.co/xxxx/poster.webp",
    "drive": "https://drive.google.com/file/d/XXXX/view",
    "mega": "https://mega.nz/file/XXXX#YYYY",
    "raw": "https://drive.google.com/file/d/ZZZZ/view",
    "sub": "https://subsource.net/subtitle/detective-conan-season-0-1996/arabic/123",
    "story": "قصة الحلقة هنا...",
    "credits": "default"
  }
```

> 💡 **ضع روابط Drive وMega العادية (رابط المشاركة).** الموقع يحوّلها تلقائياً إلى:
> مشغّل فيديو + زر تحميل. لا تحتاج تكتب رابط `preview` أو `embed`.

## 📖 شرح الحقول

| الحقل | مطلوب؟ | الشرح |
|---|---|---|
| `id` | ✅ | رقم الحلقة كنص: `"1205"` (ويمكن `"1202.5"` للحلقات الخاصة) |
| `number` | — | الرقم للترتيب (يُحسب تلقائياً من `id` لو تركته) |
| `title` | ✅ | عنوان الحلقة |
| `type` | ✅ | `manga` (مانجا/أساسية) أو `filler` (فلر) أو `remaster` (مُعاد إنتاجها) أو `special` (خاصة) |
| `date` | — | تاريخ الإضافة `YYYY-MM-DD` — يُستخدم لقسم «أحدث الإضافات» وشارة «جديد» (تظهر 14 يوماً) |
| `poster` | — | رابط صورة الحلقة |
| `drive` | ⭐ | رابط Google Drive العادي |
| `mega` | ⭐ | رابط Mega العادي |
| `raw` | — | رابط الفيديو الخام للسوفت سب |
| `sub` | — | رابط ملف الترجمة |
| `story` | — | قصة الحلقة |
| `note` | — | ملاحظة تظهر تحت القصة (مثل: مقتبسة من فصول المانجا 1130-1131) |
| `tags` | — | شارات إضافية: `["حصرية"]` |
| `credits` | — | `"default"` = الطاقم الافتراضي من `site.json`، أو قائمة مخصصة (انظر بالأسفل) |

⭐ = لازم واحد منهم على الأقل (أو `servers`).

### سيرفرات وروابط إضافية (اختياري)
لو عندك سيرفر غير Drive/Mega أو روابط تحميل إضافية:

```json
    "servers": [
      {"name": "Wistia", "url": "https://fast.wistia.net/embed/iframe/xxxx"}
    ],
    "downloads": [
      {"host": "MediaFire", "quality": "1080p", "url": "https://www.mediafire.com/file/..."}
    ],
    "softsub": [
      {"label": "تحميل الخام 2", "url": "https://nyaa.si/view/..."}
    ]
```

### طاقم عمل مخصص لحلقة معيّنة
```json
    "credits": [
      {"role": "ترجمة وتدقيق", "name": "ExcelVth"},
      {"role": "المحاكاة والبرمجة", "name": "TheConanSign"}
    ]
```
روابط حسابات أعضاء الفريق تُكتب **مرة واحدة** في `data/site.json` داخل `team`.

## 🎬 الأفلام والمانجا

- **فيلم جديد:** أضفه في [`data/movies.json`](data/movies.json) — نفس حقول الحلقة، والـ `id` يبدأ بـ `M` (مثل `"M29"`)، ويمكن إضافة `titleEn` و `year` و `trailer` (رابط يوتيوب).
- **فصل مانجا:** أضفه في [`data/manga.json`](data/manga.json):

```json
  {
    "id": "1153",
    "number": 1153,
    "title": "عنوان الفصل (اختياري)",
    "date": "2026-07-01",
    "reader": "https://cubari.moe/read/imgur/XXXX/1/1/",
    "downloads": [
      {"host": "MediaFire", "format": "PDF", "url": "https://..."}
    ]
  }
```

## ⚙️ الإعدادات العامة — `data/site.json`

- `announcement`: البانر في الصفحة الرئيسية (`show: false` لإخفائه، أو غيّر الصورة والرابط).
- `featured`: (اختياري) اكتب رقم حلقة لتثبيتها في الواجهة بدلاً من آخر حلقة، مثل `"featured": "1187"`.
- `team`: أعضاء الفريق وروابط حساباتهم.
- `defaultCredits`: الطاقم الافتراضي عند استخدام `"credits": "default"`.
- `social`: روابط التواصل في الفوتر.
- `endpoints`: روابط Google Apps Script (التعليقات، التقييم، تعليقاتكم للفريق).

## 🛟 لو ظهرت رسالة «تعذّر تحميل المكتبة»

غالباً فيه **فاصلة ناقصة أو زائدة** في ملف JSON. الموقع نفسه يعرض لك رقم السطر الذي فيه المشكلة.
- افتح **admin.html** ← تبويب **«فحص الملفات»** ← «فحص ملفات الموقع الآن».
- أو تابع تبويب **Actions** في GitHub: أي خطأ في البيانات يظهر هناك بعلامة ❌ مع الشرح.

**أخطاء شائعة:**
- نسيان الفاصلة `,` بين الحلقتين `} {` ← الصحيح: `}, {`
- فاصلة زائدة بعد آخر حلقة قبل `]`
- علامة تنصيص `"` داخل النص — اكتبها `\"` أو استخدم «» بدلاً منها.

## 🗂️ هيكل الملفات

```
index.html            الصفحة الرئيسية + المكتبة (فلترة، بحث، ترتيب)
watch.html            صفحة المشاهدة لكل الحلقات والأفلام  ← watch.html?id=1204
read.html             قارئ المانجا                        ← read.html?id=1152
admin.html            لوحة النشر (نشر/تعديل/حذف + البانر + الفحص)
404.html              صفحة الخطأ + تحويل الروابط القديمة تلقائياً
congrats.html (تعليقاتكم للفريق), Vote.html, download.html, privacy-policy.html
data/                 ← هنا كل البيانات (هذا فقط ما تعدّله عادةً)
assets/css/main.css   التصميم (الألوان في أول الملف)
assets/js/            أكواد الموقع
scripts/build-feeds.mjs  يولّد sitemap.xml و rss.xml تلقائياً
Movie28/              صفحة الفيلم 28 الخاصة
```

## 🔗 الروابط القديمة
كل الروابط القديمة مثل `1204.html` أو `M28.html` أو `M1150.html` **ما زالت تعمل** — تتحوّل تلقائياً للصفحة الجديدة. فالروابط المنشورة في تويتر وتيليجرام لن تنكسر.

## 🤖 التحديث التلقائي
عند كل تعديل على مجلد `data/` يعمل GitHub Actions تلقائياً:
1. يفحص ملفات JSON ويكشف الأخطاء.
2. يحدّث `sitemap.xml` (لجوجل) و `rss.xml`.
